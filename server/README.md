Server-side - Emoji Generator
-----------------------------

## Requirements

  - Python `$(cat .python-version)`

### Getting started

```
$ pip install -r requirements.txt
$ python app.py
```

#### venv

It is recommended that you use the venv.

If in *inux environemnts:

```
$ python -m venv venv
$ source venv/bin/activate

...

$ deactivate # exit
```
